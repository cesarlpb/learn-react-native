# 5. Extras

- Login y Registro

  - Implementa un sistema de registro para permitir que los usuarios creen una cuenta utilizando su correo electrónico y contraseña.

  - Añade un sistema de inicio de sesión para que los usuarios puedan autenticarse y gestionar sus propios archivos.

  - Modifica las funciones de almacenamiento para que cada usuario solo pueda ver y gestionar sus archivos.

  - Diseña una pantalla de autenticación que permita a los usuarios alternar entre login y registro.
